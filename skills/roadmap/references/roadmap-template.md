# Roadmap template

Use this template for the content of the roadmap. `stores.md` says how each store holds it. Delete the guidance lines in parentheses.

```markdown
# <Product name> roadmap

Outcome: (One sentence. The change for a user that the product exists for.)
Updated: <YYYY-MM-DD>

## Pre-MVP

Outcome: (What we know at the end of this phase that we guess today.)
Exit check: (An observation, for example "three people describe the problem without a prompt".)
Status: <active | done>

### <Item title>

- Status: <now | next | later | done | dropped>
- Problem: (Who has it, and what it costs them.)
- Assumption: (The belief that this item tests or depends on.)
- Test: (The cheapest test, and the result that stops the work.)
- Appetite: (The time the user will spend, for example "3 days".)
- Confidence: <guess | heard | committed | tested | shipped>
- Evidence: (Links to notes, issues, or conversations. Empty for guess.)

## MVP

Outcome: (...)
Exit check: (...)
Status: <active | waiting | done>

(Items.)

## Post-MVP

Outcome: (...)
Exit check: (...)
Status: <waiting | active | done>

- <Later item in one line>

## Dropped

- <YYYY-MM-DD> <Item title>: (The reason and the evidence.)

## Decision log

- <YYYY-MM-DD> <Change>: (The evidence. Confidence before and after, if it changed.)
```
